# Changelog — 2026-06-05

Все изменения в `v1/index.html`.

## Social Intel — стабильный мини-дашборд (редизайн)
- Убрана авто-ротация строки (`setInterval(rotateSocialIntel, 10000)` + пипсы) → **3 фиксированные строки сразу**: **LOUDEST / HOT / TOP MSG**.
- Mood и Activity убраны намеренно — дублировали виджеты Community Sentiment и Online Users.
- Таймстамп **⟳ now → Nm ago** (тихий пересчёт снапшота раз в 120с, обновление подписи раз в 30с).
- **TOP MSG** остаётся кликабельным → прыжок и подсветка сообщения в чате.
- Карточка стала авто-высоты; читаемость проверена на dark и snow темах.
- Подчищен мёртвый код: `siLines`, `rotateSocialIntel`, `BOX_EXTRA`, неиспользуемые `.si-rotate / .si-pip / .si-dots`.

## Иконка отправки сообщения
- Кнопка `.send-btn`: юникод ▶ заменён на пиксельный SVG «бумажный самолётик»; `fill` → `currentColor` (наследует цвет/тему и hover).

## Профиль — переработка модалки PROFILE (редактор)
- **Превью сверху**: крупный троль (150px) + ник, всё **live** (цвет/оттенок/имя меняются мгновенно).
- **Свотчи цвета**: в один ряд (`flex`), без скруглений (квадратные).
- **Тумблер** Show badges — в стиле `settings-toggle` (квадратный, акцент).
- Иконки save/× крупнее; добавлен нижний отступ; убран градиент за троллем; поверх модалки — **CRT-скан-линии**.
- Кнопки **LIGHTER / DEFAULT / DARKER** — капсом.
- Заголовки приведены к стилю Settings (серые `#888`/`#e0e0e0`, без синего), размеры шрифтов в Settings и Edit Profile унифицированы (лейблы 13px, подсказки 14px).
- Обводка инпута ника при фокусе — акцентная (`var(--ac)`), display name предзаполняется.
- Статус «Invest in a troll.box guys» убран (фича статусов — позже).

## Мобильные страницы профиля и настроек
- **Edit Profile** на мобилке — полноэкранная страница: шапка слева (← + EDIT PROFILE), большая кнопка **SAVE** внизу (в стиле кнопки EDIT PROFILE).
- **Edit Profile** и **Settings** открываются **поверх навбара** (навбар скрывается) как цельные карточки с рамкой — единое обрамление со страницей **YOU** (`inset: 8px`, rect `[8,8,367,804]`).
- Фон у edit profile / профиля / настроек приведён к фону страницы боксов — `#0a0a0a`.
- Заголовок EDIT PROFILE приглушён до `#e0e0e0` (как SETTINGS / PROFILE).

## Акцентные цвета — только в боксах и их терминалах
- Профиль, настройки и навбар больше **не подтягивают цвет последнего бокса**: `--ac` запинен зелёным `#8CE45A` (с оттенками под темы amber/hacker/aurora) на `#profileModal / #profileEditModal / #settingsModal / #mobileSettingsView / #mobileProfileView` и `.mobile-nav`.
- Активный таб навбара — всегда главный зелёный.

## Навбар (мобилка)
- Пункт **YOU → ME**; иконка ME оптически выровнена под левотяжёлую подпись.

## Большие CTA-кнопки — ретро-ховер
- На hover (и `:active` на мобилке): **двойная рамка** акцентом + тёмно-зелёная заливка + **стрелки `▶ TEXT ◀`** по бокам (пиксельная иконка как `mask`, красится в `var(--ac)`).
- Стрелки выезжают по анимации, идеально центрированы по вертикали (замер: дельта 0).
- Применено к: `auth-btn`, `welcome-auth-btn`, `create-widget-btn` (CREATE/ADD WIDGET), `pe-save-mobile` (SAVE), `tour-next/tour-m-next`.
- У маленьких `modal-btn.confirm` (CREATE → в модалках) стрелки убраны (уже есть глиф+текст), рамка-ховер оставлена.
