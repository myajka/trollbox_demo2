# PROD AUDIT — changelog pro max

**Что сверяем:** прод `troll.ing` ↔ источник правды дизайна `v1` (этот проект).
**Скоуп:** только дизайн/UI-UX — цвета, фоны, формы, отступы, скругления, шрифты, иконки, анимации. НЕ техническая реализация. Сторонние подключения (firebase и т.п.) не отражаю. Различия от данных/режима/аккаунта — не баг.
**ЦВЕТ = БАГ:** скрины эталона и прода сверяются в ОДНОЙ теме. Если элемент (текст, рамка, фон, иконка, кнопка) отличается по цвету от эталона — это **баг**, пишем как правку. Частый паттерн прода: акцент темы не подтянулся и элемент покрасился дефолтным/алиасным цветом (белый/серый там, где в эталоне зелёный/жёлтый/цвет темы).
**Процесс:** эталон-скрин → прод-скрин → расхождения подтверждаются в чате → только подтверждённое пишется сюда.
**Дата:** 2026-06-16.

### Все боксы · десктоп · темы hacker + amber

**Область:** дефекты темы общие для **ВСЕХ боксов** (не только FIFA). Подтверждено на скринах GENERAL, FIFA, BLOCKCHAIR — баги одинаковые во всех. Конкретные виджеты ниже (MATCHES, Search your team, VOTE, BTC PRICE и т.п.) — лишь примеры; правило применять к аналогичным элементам в любом боксе.

**Корень:** в проде акцент темы не подтянулся — элементы взяли дефолтный белый/серый. Чинить **в обеих темах** (hacker и amber — один принцип), значения брать из эталона `v1/index.html` (блоки `[data-crt-theme="hacker"]` / `[data-crt-theme="amber"]`).

**Палитра-акценты эталона (использовать в фиксах ниже):**

| роль | hacker | amber |
|---|---|---|
| main (текст/иконки-акцент) | `#50e850` | `#d4a54a` |
| bright (заливка кнопок, фокус, glow) | `#00ff41` | `#ffb347` |
| muted (второстепенный текст) | `#309030` | `#8a6e3c` |
| border (рамки) | `#0f3f0f` | `#504020` |
| divider (разделители) | `#0a280a` | `#302818` |

1. **Названия боксов (левый список)** — прод: белые. → `color` = main. Глиф `#` НЕ трогать (остаётся цветом конкретного бокса).
2. **Кнопка MY BOX** — прод: белая рамка/текст. → `border-color` = border, `color` = main (hacker `#0f3f0f`/`#50e850`, amber `#504020`/`#d4a54a`).
3. **Центральная шапка (название активного бокса)** — прод: белый текст (`#GENERAL`, `#FIFA`, `#BLOCKCHAIR` …). → название `color` = main; `#` = цвет бокса.
4. **Заголовки виджетов правой панели** (любые: `TERMINAL`, `[ACTIVITY PULSE]`, `[BTC PRICE]`, `[XMR PRICE]`, `[MATCHES]`, `DEGENS ONLINE` …) + акцентные числа (цена, счётчики) — прод: белые/серые. → `color` = main; крупные значения (напр. цена `$65,731`) = main.
5. **Карточки/строки внутри виджетов** (напр. MATCHES) — прод: белые/серые рамки и текст. → рамка `border-color` = border; текст = main; акценты/счёт = bright.
6. **Инпуты в виджетах** (напр. `Search your team…`) — прод: белая рамка. → `border-color` = border, `:focus` border-color = bright, текст `color` = main.
7. **Кнопки в виджетах** (напр. `VOTE …`, `VIBES CHECK`) — прод: серые. → `border-color` + `color` = main.
8. **Пагинация** (напр. матчи `‹ prev … next ›`) — прод: серая. → текст `color` = muted, кнопки prev/next `border-color` = border, активная цифра = main.
9. **Контролы виджета в шапке** (свернуть/переместить/закрыть) — прод: серые + неверная форма `+/−`. → (а) `color`/`fill` = main; (б) вернуть набор иконок эталона: стрелки перемещения `↑ ↓` + закрытие `✕` вместо `+/−`.
10. **Профиль (ник) + кнопки Settings / Logout** — прод: белые/серые. → ник `color` = main; кнопки `border-color` = border, `color` = main.
11. **Поиск (низ левой колонки)** — прод: серые лупа/рамка. → иконка (`fill: currentColor`) `color` = main, рамка `border-color` = border.
12. **Обводки/рамки слишком тёмные и неконтрастные** — прод (hacker, amber): рамки виджетов, карточек и разделители почти сливаются с фоном (низкий контраст). → привести `border-color` к border-акценту эталона (hacker `#0f3f0f`, amber `#504020`), разделители — к divider (hacker `#0a280a`, amber `#302818`); не делать рамки темнее эталона. Цель — рамки чётко видны, контраст как в эталоне.
13. **Логотип `TROLL.BOX` (шапка левой колонки)** — прод: иконка тролля + текст логотипа белые/серые. → текст `color` = main, иконка (`fill` / `fill: currentColor`) = main (hacker `#50e850`, amber `#d4a54a`). Подпись `beta` — тоже акцент темы.
14. **Фон попапа сообщения (`msg-popup`)** — прод: серый/светлый (дефолтный `#161616`). Эталон: тёмный в цвет темы. → `background` = panel-bg темы (hacker `#05130a`, amber `#15100a`); рамка `border-color` = border темы.
15. **Фон эмодзи-кнопок в попапе** — прод: серые плашки (дефолт `#1e1e1e`). Эталон: тематические. → `background` = hacker `#0a1f0a` / amber `#201810`; `:hover` `background` = hacker `#0f2f0f` / amber `#2a2012`; рамка при hover = main.
16. **Цвет ника в пунктах попапа** (`Reply @X`, `Show @X profile`) — прод: ник красится неверным (рандомным/дефолтным) цветом. → подтягивать **цвет ника конкретного юзера** — тот же цвет, которым его ник отображается в чате/сообщениях (НЕ рандом, НЕ дефолт).

_Исключено как НЕ-баг (контент/состояние/аккаунт):_ текст объявления (pinned-сообщение в эталоне vs beta-notice в проде — разные компоненты), строка настроения / `Loading profile` под ником (состояние/данные аккаунта), число DEGENS/FANS ONLINE, состав боксов и сообщений, набор эмодзи-реакций в попапе, отсутствие пункта `Delete message` в попапе (зависит от прав / своего бокса).

_Не баг (контент/состояние/аккаунт):_ состав боксов и категории, счётчики участников, подсветка активного бокса, цвета `#`.
