# Changelog — 2026-06-08

Все изменения в `v1/index.html`.

## Реальное отключение CRT (тумблер настроек)
- Тумблер «CRT effects» в настройках раньше только переключал свой класс — теперь **реально гасит** эффекты: скан-линии (`.app::before`), beam (`.crt-beam`), noise (`.crt-noise`), виньетку/мерцание (`.app::after`, `body::before`), скан-линии над модалками и общий text-glow.
- Реализовано через флаг `html.crt-off` (out-специфичит даже `!important`-правила тем).
- Выбор **сохраняется** в `localStorage` (`tb_crt`); оба тумблера (десктоп + мобилка) синхронны.
- При выключенном CRT **boot-скан на Boxes не играет** (показываются только live-превью).

## Подсветка ответа тебе (reply)
- Последнее сообщение в боксе, которое **отвечает текущему юзеру**, подсвечивается фоном в **оттенке акцента бокса** (`color-mix(var(--ac) 7%)`) + акцентная полоса слева — чтобы не пропустить ответ.
- Правило (в `renderChat`): берём последнее сообщение, у которого `message.replyTo.author === ник текущего юзера` (регистронезависимо), и вешаем на него класс `.msg.reply-to-me`. Текущий юзер — из `#profileDisplayName` (в проде — из авторизации).
- См. «Integration / backend notes» ниже.

## Чистка юникода в интерфейсе → SVG
- Юникод-пиктограммы в UI (на телефоне подменялись на эмодзи/тофу) заменены на инлайн-SVG: **▲▼** (рост/падёж в маркет-виджетах и mood-кнопках), **▶** (LIVE STREAMS), **★** (GITHUB TRENDING), **⚑** (анонс); шестерёнка **⚙** у Settings убрана.
- Цвета сохранены через `currentColor` (работают акценты/темы).
- **Не тронуты:** эмодзи в сообщениях чата, реакции и эмодзи-пример в модалке создания бокса.
- TODO: заменить временные SVG-заглушки на финальные иконки от Ви (см. `TASKS.md` #7).

## My Box — терминал (фиксы)
- **Live-добавление виджетов:** на мобилке виджеты примонтированы в центр (`#mobileTermMount`), а изменения шли только в скрытый `#right-panel` — теперь добавление/удаление/перемещение **сразу видно** (общий `refreshActiveTerminal()` перемонтирует на мобилке).
- **Иконки управления** виджетами в My Box-терминале приведены к виду боксов: те же пиксельные SVG-стрелки (голова + древко) вместо юникод-треугольников; крестик выровнен по высоте (14px).

## Integration / backend notes (для склейки с бэком)
Памятка для интеграции фронта с боевым бэком. Новых фич/эндпоинтов от бэка тут НЕ требуется.

**Чисто фронт — вливать как есть, бэк не трогает:**
отключение CRT (localStorage `tb_crt`), чистка юникода → SVG, цвет ботов по боксу, фиксы/иконки My Box-терминала, навбар/шапки/выравнивания, My Box-источники (localStorage `tb_mybox_sources`), профиль (localStorage `tb_profile`).

**Подсветка ответа (reply) — потребляет существующие данные, не новая фича:**
- Нужно, чтобы сообщение из API несло **`replyTo.author`** (ник/id того, КОМУ ответили), и фронт знал **id/ник текущего юзера** (из авторизации).
- Если реплаи в боевом API уже так и приходят → подсветка работает сама. Если поле называется иначе — это **маппинг на стороне склейки**, не задача на бэк.
- Сравнение регистронезависимое по нику. На демо-данных подсветка не видна (в моках нет ответов текущему юзеру) — это нормально, в проде её зажигают реальные реплаи. **Демо-сиды НЕ добавлялись в код.**
- Расширения (непрочитанное/«тебе ответили в #ai»/уведомления) — отдельные задачи на бэк, в этот релиз НЕ входят.

**Аноним — гейты только на фронте (НЕ серверный контроль):**
- лимит «3 сообщения» (`anonMsgCount`, в памяти), reg-wall на реакции/создание бокса — это UX-наджи, легко обходятся (перезагрузка/девтулз). Для серверного enforcement нужен бэк — отдельная задача (см. `TASKS.md` → «Аноним — заметки на v2»).

**Юникод-иконки:** сейчас временные SVG-заглушки (`.tri` и пр.) вместо ▲▼★▶⚑. Финальные иконки от Ви заменят их позже (`TASKS.md` #7) — на бэк не влияет.
