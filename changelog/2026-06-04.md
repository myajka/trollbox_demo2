# Changelog — 2026-06-04

Все изменения в `v1/index.html`.

## Профиль — модалка PROFILE (новое)
- **Редактор профиля** `#profileEditModal`: 7 свотчей цвета тролля, оттенок **Lighter / Default / Darker**, **Display name** со счётчиком `N/16`, тумблер **Show badges in profile**.
- Цвет/оттенок применяются **live** (CSS `hue-rotate`+`brightness` на аватаре). **Save** → `localStorage['tb_profile']`, **Close / × / Esc** → откат черновика.
- Открывается из карточки профиля (десктоп-модалка и мобильный профиль-вью). `applyMyProfile()` синхронит аватар/ник/бейджи во всех местах.
- Тумблер бейджей прячет блок Badges в профиле.

## Онбординг — тур по фичам (новое)
- Тур при первом входе в приложение (anon/auth), флаг `onboarded` в `localStorage`. 4 шага: Welcome / Boxes / Chat & Terminal / Your Troll.
- **Десктоп** — коучмарки: затемнение + подсветка реального блока (spotlight) + тултип. **Мобилка** — свайп-слайды с иллюстрацией, точками-индикатором, Skip.
- Автосмена шага 8с + **Next** + **×**, Skip на любом шаге. Пункт **«Show tour again»** в Settings (десктоп + мобилка).

## Реплай на сообщение (новое)
- Пункт **Reply** в попапе сообщения подключён (`startReply`). Над инпутом — **reply-chip** (ник в цвете автора, превью 24 симв., отмена по × / Esc).
- К сообщению крепится `replyTo {idx, author, preview}`, синк через Firebase (POST + чтение в `ingestFbMsg`).
- В чате — **цитата** `@USER: превью…` с **L-уголком** в цвете тролля автора; клик → скролл+подсветка оригинала (`highlightChatMsg`). Удалённый оригинал → «(deleted)» без клика.
- Один уровень. Реплай из My Box → переключение на исходный бокс. Фикс grid-раскладки для `has-tag` сообщений (цитата на всю ширину).

## Реакции на сообщения — синк через Firebase
- Эмодзи-реакции теперь **сохраняются и видны всем**: хранятся в Firebase по пути `/rooms/{room}/reactions/{idx}/{emoji}/{clientId}`, живой синк через SSE (`applyReactionUpdate` / `setReactionPath`).
- Стабильный **`myClientId`** на устройство; тоггл (`toggleReaction`) — оптимистичный апдейт + запись/удаление в Firebase.

## My Box (переименование Terminal/My Mix + позиция)
- **My Mix → My Box** во всех видимых строках (внутренний id `mymix` и ключи `localStorage` не трогали — без миграции).
- **Мобильный навбар:** таб Terminal → **My Box**; иконки Boxes (сетка 2×2) и My Box (пиксельная коробка).
- **Переключатель Box / Terminal** внутри бокса (мобилка). В Terminal-виде **верхняя шапка с названием бокса остаётся** — переключатель меняет только контент под собой (виджеты монтируются в центр: `mountBoxTerminal` / `unmountBoxTerminal`).
- My Box ведёт себя как обычный бокс: по умолчанию чат-фид + переключатель на его терминал. Подсветка таба навбара по контексту комнаты.
- **Десктоп:** My Box — отдельная **кнопка-карточка** сверху сайдбара (рамка, иконка-коробка, «MY BOX» без `#`, hover/active — акцентный зелёный `#8CE45A`); на мобилке скрыта (там My Box — таб навбара).

## Индикатор подключения (новое)
- Пиксельный **онлайн-дот**: состояние из `readyState` всех Firebase SSE-стримов + `navigator.onLine` (`connSet` / `connEvaluate`, опрос 4с). Жёлтый connecting → зелёный live → красный offline.
- **Десктоп** — в правом-верхнем углу аватара тролля в PROFILE. **Мобилка** — бейдж 6×6 у названия бокса в шапке чата, полупрозрачный, акцентный зелёный `#8CE45A`.

## Экран Boxes — оживление (мобилка)
- **Live-превью последнего сообщения** под каждым боксом: ник (серый, полупрозрачный) + текст **Roboto**, обрезка 26 симв. + фейд по краю. Typewriter при заходе на вкладку + live-обновление по SSE (`ingestFbMsg`). Фиксированная высота строки (каретка не дёргает раскладку).
- **Решётка `#`** перед названием бокса — в акцентном цвете бокса.

## Mobile UI / полировка
- Строки боксов на **всю ширину** (убраны боковые отступы списка, контент инсетится на 16px); линия под шапкой сайдбара — edge-to-edge.
- Высоты шапок трёх колонок выровнены (44px) — нижние линии на одном уровне.
- Подпись версии **v0.1** в шапке сайдбара (мобилка).
- Убрана лишняя верхняя обводка над GENERAL.
