# Changelog — 2026-06-07

Все изменения в `v1/index.html`.

## Модалка создания бокса (`#createModal`) — переработка
- **Акцентный цвет бокса** — палитра `BOX_COLORS` (14 цветов: 7 из `PE_COLORS` + 7 ярких), свотчи 2 ряда по 7. Выбор красит имя/фокус/кнопку CREATE в цвет бокса (live).
- **Имя бокса** — фиксированный префикс `#` в цвете акцента, имя вводится после него (белым), лимит 10 символов.
- **Категория** — `<select>` → текстовый инпут (лимит 12) + подсказка.
- **Реакции** — инпут до 5 эмодзи (`Intl.Segmenter`), пример-эмодзи показан оверлеем ч/б + полупрозрачным (прячется при вводе).
- **Access** — нативный `<select>` заменён на кастомный дропдаун (`.modal-select`): стрелка с отступом, список ровно по ширине поля.
- Заголовок `# create box` → **CREATE BOX**; лейблы полей капсом в стиле Settings (#888/#e0e0e0, 13px).
- Кнопка **CREATE → SEND REQUEST** + подпись о модерации заявки; CANCEL компактнее, SEND REQUEST шире.

## Профиль и редактирование профиля — единое окно (десктоп)
- Профиль и редактор — **одно окно одного размера**, по тапу EDIT правая часть меняется на форму (превью слева остаётся).
- **Горизонтальная вёрстка**: слева крупное превью тролля + ник, справа контент/форма и кнопки.
- Кнопка **SAVE внизу** (десктоп + мобилка), иконка save из шапки убрана; back/Save/Esc → возврат к виду профиля.
- **Bio**: строка в профиле (над Joined, в одном блоке с ним, шрифт Roboto) + инпут в редакторе (лимит 54).
- Скроллбар модалок — в стиле интерфейса (тонкий, тёмный).
- Высота шапки всех модалок (профиль/edit/настройки) унифицирована — **48px** (контент не прыгает).
- Тултипы бейджей — плавающий элемент на уровне `<body>` (fixed), больше не обрезаются скроллом/превью.

## Акцентные цвета — только в боксах
- Профиль, настройки и навбар (моб.) больше не подтягивают цвет последнего бокса — `--ac` запинен зелёным (+ оттенки под темы). Активный таб навбара всегда главный зелёный.
- Мобилка: Edit Profile и Settings открываются **поверх навбара** как полноэкранные карточки; единое обрамление со страницей профиля; фон `#0a0a0a`; пункт навбара **YOU → ME**.

## General / My Box — лента из разных боксов
- Тег бокса-источника в стиле сайдбара: **`#` в цвете бокса + название белым**, вынесен из левой колонки.
- **Текст сообщения во всю ширину** (float-раскладка тега и аватара) — длинные имена боксов (`#STABLECOINS` и т.п.) не создают пробелов.
- Убран фиктивный `#GEN` — у каждого сообщения тег реального бокса; `msgSrcTag` матчит и «скобочные» имена (`[STABLECOINS]`).
- Больше примеров: 11 языков с переводами + длинные теги боксов.
- Интервал между сообщениями на мобилке увеличен (`padding-bottom 3→6px`).

## CRT boot-in — экран Boxes (мобилка)
- Пошаговая «включение CRT» при заходе на Boxes: скан-линия **прыгает по шагам** сверху вниз, каждый бокс резко появляется только когда луч **полностью прошёл его низ** (под линией пусто), уже с последним сообщением; без typewriter после и без горизонтальных сдвигов.
- Реализовано на чистом JS (`setInterval`), не на CSS-keyframes — стабильно проигрывается.
- **Правило показа:** скан играет **один раз** — сразу после регистрации/логина (`welcome → in`). Вход запоминается (`localStorage: tb_authState`), поэтому refresh и переходы между вкладками показывают только анимацию появления последних сообщений (live-превью).

## My Box (чат-вью) — персональная лента из чатов и ботов
- Лента собирается из двух типов источников: **чаты каналов** (люди) + **отдельные боты** из любых каналов; выбираются независимо (можно только боты, только чаты или микс).
- **Пустой онбординг:** заголовок «Build your feed», иконка — тролль с рупором (`trolls/my_box.png`), одна CTA **「＋ Add sources」** + чипы быстрого добавления (4 канала в одну строку, без `general`; боты). На пустом экране **строки ввода нет** — она появляется, как только добавлен источник.
- **Строка «Following … · Edit»** над лентой при наличии источников (перечисление источников + `+N`); Edit открывает пикер.
- **Пикер источников** — две вкладки **Chat boxes / Bots**: чаты каналов и боты отдельными списками, тоглы (✓ADDED/+ADD), поиск по каждой вкладке.
- **Адресат над инпутом:** чипы только добавленных чатов; выбранный = цель отправки, плейсхолдер «Type to #…»; без чатов инпут заблокирован («Add a chat to post here»). Отправка маршрутизируется в выбранный канал.
- Источники сохраняются (`localStorage: tb_mybox_sources`); алиасы каналов (`eth`/`sol` == `btc`) учтены.

## Виджеты — добавление в терминал My Box
- У каждого виджета в боксе (рядом со стрелками) — кнопка **«+»**: добавляет/убирает виджет в терминал My Box (toggle **«+» ↔ «−»**), тултип «Add to My Box» (через глобальный `[data-tip]`-попап; на мобилке крупнее).
- Стрелки порядка перерисованы (голова + древко), иконки 10×10 выровнены; на мобилке крупнее, с тап-зонами ~28px.
- Пикер терминала — **только виджеты** (вкладки Widgets/Bots убраны; боты теперь добавляются в чат-вью My Box).

## Боты в цвете своего бокса
- Иконка, ник и (слегка подкрашенный, читаемый) текст бота берут **акцентный цвет бокса**.
- В обычном боксе — цвет активного бокса (учтены алиасы: в #ETH/#SOL не «протекает» цвет #BTC). В смешанных лентах (My Box / General) — цвет **бокса-источника** каждого сообщения. В плоских списках/карточке бота — цвет **домашнего** бокса бота.
- Аватар бота перекрашивается инлайн-SVG (тело→акцент, тень→затемнённый акцент, глаза сохранены) — работает и на `file://`; результаты кэшируются.

## Скроллбары — фикс под Safari 18.2+
- Safari глушит `::-webkit-scrollbar`, если задан `scrollbar-width`/`scrollbar-color` ≠ `auto`. В WebKit (Chrome+Safari) сбрасываем эти свойства в `auto` (`@supports selector(::-webkit-scrollbar)`), Firefox продолжает использовать стандартные.
- Глобальный webkit-фолбэк (тонкий тёмный скролл) для элементов без своих правил (модалка настроек и пр.).
- Тумб ленты чата сделан видимым по умолчанию — скролл виден при прокрутке во всех чатах/на тач.

## Анонимный юзер (v1) + reg-wall
- Аноним **свободно смотрит и собирает** (My Box — полный доступ), но публичные действия — за регистрацией.
- **Лимит сообщений:** 3 суммарно (в памяти, не персистится; реплай считается) → дальше reg-wall.
- **Реакции:** попап показывается, но клик по реакции → reg-wall.
- **Создание бокса:** «+» на месте, клик → reg-wall (модалка создания не открывается).
- **Reg-wall** — компактная модалка **поверх чата** (чат виден за ней), закрывается крестиком/тапом по фону; **контекстный текст** под действие (реакция / создание / лимит / профиль); кнопки **Sign up / Log in** → вход как полноценный юзер.
- **Edit Profile (аноним):** аватар залочен на анон-маску (`anon.svg`), цвет/био/бейджи скрыты, ник редактируется, кнопка «Log in to unlock more».
- **Профиль гостя:** скрыты фейк-статы, бейджи и лишний разделитель под ними (`body.is-anon`).
- Вход через соц-кнопки welcome (𝕏 / Discord / Telegram / Web3) и форму = **полноценный аккаунт** (`auth`); аноним — только через **JOIN ANONYMOUSLY**.
- **LOG OUT** теперь рабочий — возврат на welcome, очистка сохранённого входа (`tb_authState`), сброс лимита анона; на все 3 кнопки логаута.

## Навбар и шапки (мобилка)
- **Навбар:** активный пункт стал **нейтральным** (светло-серый / тёмный на snow) вместо акцентного — цвет кодирует идентичность бокса/юзера, навигация спокойная.
