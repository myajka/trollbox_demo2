# Changelog — 2026-05-28

Все изменения в `v1/index.html`.
Коммиты: `0d13777`, `3e50b50`.

## Фиксы
- **Каретка ввода** — переписан `setupBlockCursor`: ширина текста меряется реальным шрифтом инпута (зеркальный span) + привязка к `selectionStart`. Чинит чат и поиск.
- **Закреплённое сообщение** — показывается на мобилке (убран `display:none` в media-query).
- Удалена надпись **«voted by chat»** из виджета Fact of the hour.

## Профили
- **Клик по нику/аватарке** (в чате и списке онлайн) открывает профиль юзера — `openUserProfile()` + диспетчер `openProfile()`. На чужом профиле скрыты EDIT / LOG OUT.
- **Тултипы на бейджах** профиля (дата получения / условия разблокировки).

## Боты
- **Карточка бота** `openBotProfile()`: создатель (кликабелен), модель, кол-во сообщений, команды, online/uptime, кнопки VIEW CODE, REPORT, **ADD TO MY MIX**, **MUTE BOT** (скрывает сообщения конкретного бота).

## My Mix
- **Чат** — агрегатор только добавленных ботов (`myMixBots`); по умолчанию пустой с инструкцией + чипы ботов; теги сообщений в цвете бокса-источника.
- **Терминал** — конструктор: кнопка **ADD WIDGET** → пикер «бокс → виджеты» с поиском и проектным скроллбаром; добавление / удаление / реордер; сохранение в `localStorage`.
- Скрыты тоггл Show bots и плашка-объявление; акцент = как у general.

## Виджет Social Intel (новый)
- Динамический расчёт на клиенте из `CHATS[box]`: активный юзер, топ-сообщение, топ-слова, тематический инсайт, кол-во сообщений, настроение.
- Раскатан на все боксы; берёт **акцент и данные своего бокса** (в `PANELS` передаётся id комнаты — фикс для ETH/SOL, которые используют панель BTC).
- **Ротация строки каждые 10с** с fade + индикатор-квадратики прогресса; стрелки реордера; бейдж LAST 1H у заголовка.
- Весь текст — акцентного цвета; пунктирная обводка без заливки; фикс-высота.
- **Топ-сообщение кликабельно** → `highlightChatMsg()` прокручивает чат к сообщению и подсвечивает его (с переключением бокса при необходимости).

## Прочее
- Тоггл **Show bots / Hide** — рабочий (скрывает/показывает сообщения ботов).
- Иконка ℹ убрана из шапки TERMINAL.
- Счётчик онлайн-юзеров — шрифтом и размером заголовка (`CHNOPixelCodePro` 14px).

## Mobile
- Навбар виден везде (включая чат бокса).
- Тап по навбару закрывает settings-вью и открытые модалки.
- Точки онлайн-юзеров — в один ряд (как на десктопе).
- Social Intel — строка в одну линию с троеточием (без переноса на 2 строки).

## Структура репозитория
- Весь контент приложения лежит в **`v1/`** (`v1/index.html` + ассеты + `trolls/`).
- Бывшая `v2/` (тема **darkglass**) перенесена в **`v1/darkglass/`**; кнопка темы в приложении ведёт на `darkglass/?from=v1`.
- В корне: `v1/`, `changelog/` и `index.html` (редирект на `v1/`).
