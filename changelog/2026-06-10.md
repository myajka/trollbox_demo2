# Changelog — 2026-06-10

Все изменения в `v1/index.html`. Новые ассеты: `v1/fifa_box/flags/` (флаги flag-icons, форматы `1x1/` и `4x3/`).

## FIFA — новый бокс «World Cup 2026»
Большая доработка FIFA-бокса. Виджеты строятся в `PANELS.fifa`, данные матчей — `FIFA_MATCHES` (3 матча: ARG–BRA, FRA–ENG, ESP–GER).

### Порядок и чат
- `#FIFA` поднят **третьим** в общем списке боксов (после `#BTC`).
- В чат добавлены реплики фанатов и **сообщения от `news_bot`** (старт ARG–BRA, фитнес Мбаппе, рекорд по билетам, апгрейд VAR и др.).

### `[COUNTDOWN]` (бывш. NEXT MATCH)
- Переименован, чтобы не дублировать `UPCOMING MATCHES`.
- **Автолистание слайдов каждые 8с** (`fifaSlideStart`, по кругу из 3 матчей); клик по точке листает вручную и сбрасывает таймер.
- Живой обратный отсчёт d/h/m/s, флаги команд, подпись часового пояса (`fifaTz()`, напр. `GMT+3`).

### `[UPCOMING MATCHES]`
- Показывает **ближайшие 3** матча (`fifaUpcoming(3)`), оформлены карточками.
- Реальные флаги (SVG), даты под днём недели — **жёлтые** (акцент), центральный блок со странами выровнен по центру, время + часовой пояс справа.

### `[WHO WILL WIN?]`
- **Кнопки голосования** (VOTE ARG / VOTE BRA с флагами) подняты над полосками, увеличены.
- **Кулдаун 30 мин**: после голоса кнопки неактивны, на hover — тултип «You can change your vote in MM:SS» с живым отсчётом (`tickFifaVote`); по истечении снова активны.
- Цвет Бразилии — **зелёный с флага** (`#309e3a`) вместо ярко-жёлтого.
- График «How opinion shifted» — **12 получасовых снимков** опроса, разбросанные проценты (38–66%); легенда цветов и подписи времени под графиком убраны, остались только **два крайних времени** (раннее · свежее). По наведению на столбец — подсветка + тултип со временем и раскладом. **Насыщен только правый (свежий) столбик**, остальные приглушены (opacity 0.38).

### `[FIFA NEWS]`
- Новый виджет: динамически собирает **последние 3 сообщения от `news_bot`** из чата FIFA (`fifaNewsWidget`). Flex-вёрстка — перенос строки выравнивается по началу текста, а не по маркеру.

### `[FACT OF THE DAY]`
- Новый виджет внизу панели: **случайный исторический факт про ЧМ/ФИФА** из пула на 12 фактов (`fifaFactWidget`).

### Флаги
- Эмодзи-флаги заменены на **SVG flag-icons** (`fifaFlag(cc)`, путь `fifa_box/flags/4x3/`) — рендерятся одинаково на всех платформах (на Windows эмодзи показывались буквами). Англия — флаг Св. Георгия (`gb-eng`). В репо лежит полный набор флагов для бэка, лишние файлы пакета удалены.

### Анимированный фон-лого
- Точечное (halftone) лого ФИФА с волновой анимацией яркости, очень прозрачное, за сообщениями (`.fifa-bg`, маска из SVG-силуэта + дот-грид + sweeping-градиент). Показывается только в FIFA-боксе.
- **Десктоп**: крупное, по центру окна чата (`auto 90%`, небольшие отступы от рамки).
- **Мобилка**: одна крупная иконка по центру (`auto 64%`, опущена ниже шапки).

### Прочее
- Мобильная шапка бокса: вернулось описание (`[WORLD CUP 2026]`) более прозрачным текстом.

## Integration / backend notes
Чистый фронт. Новый ассет-каталог `v1/fifa_box/flags/` (SVG-флаги, оба формата) — самодостаточен, можно отдавать как есть; на проде путь к флагам и реальные данные матчей/опроса/новостей подставит бэк. Голосование/кулдаун/факты сейчас на клиентских данных (демо), эндпоинтов не требуют.
