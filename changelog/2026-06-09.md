# Changelog — 2026-06-09

Все изменения в `v1/index.html` (+ новые ассеты `v1/search_icon.svg`, `v1/send_message_icon.svg`).

## My Box — кнопка на десктопе (редизайн)
Пиннер-кнопка «MY BOX» вверху сайдбара стала двухстрочной и информативной (`.mybox-btn`):
- **`@N`** — бейдж ответов текущему юзеру (подмножество общего счётчика), янтарный, скрыт при нуле.
- **`(N)`** — кружок-счётчик всех сообщений агрегированной ленты (`buildMyMix().length`), шрифт Roboto.
- **Превью** последнего сообщения — карусель по последним 6 (раз в 3.5с), ник пиксельным шрифтом, словобезопасная обрезка с `…` (без висящей буквы).
- Заголовок «MY BOX» крупнее (15px); на hover/active **весь текст** (ник/сообщение/подпись) зеленеет.
- Пустой бокс: подпись «No sources yet — tap to add» (medium, не курсив) + **зелёный градиент** справа за текстом (transparent → `#46792F` → `#62B83C`).
- Реализация: счётчики/превью live-обновляются по таймеру (`myBoxBtnTick`), TDZ-фикс — мобильная проверка через `matchMedia`, не `isMobile()` (вызывается до её инициализации).

## VIP-аватары разработчиков
- Ник `kyoshee` → тролль-Луффи, `boss_nikitos` → тролль-Кренг. Маппинг в `getTroll()` (`VIP_TROLLS`, регистронезависимо), перебивает случайный пул. Размер — стандартный чат-слот 24px (вписываются без искажений). Ассеты в `v1/trolls/our_avatars/` (gitignored, WIP).

## Адаптив боковых колонок (900–1120px)
- Боковые колонки сделаны резиновыми: `grid-template-columns: clamp(240px,26vw,360px) 1fr clamp(...)`. Чат (центр) теперь **всегда шире** боковых; на широких экранах боковые упираются в прежние 360px. Раньше на ~1010px чат (258px) был у́же боковых (360px).
- Внешние отступы раскладки: `gap` между колонками 8→**10px**, `padding` от рамки браузера 8→**12px**.

## Сворачивание левой колонки (десктоп)
- Кнопка `[<]` в шапке сайдбара сворачивает колонку в узкий рельс (128px): только цветной `#` + короткое имя бокса (счётчики/превью/теги скрыты). Шеврон поворачивается, выбор запоминается (`localStorage` `tb_left_collapsed`), восстанавливается на десктопе.
- В свёрнутом виде остаётся **тролль из логотипа** (надпись TROLL.BOX обрезается), профиль/футер компактны.
- Строка поиска в свёрнутом виде — суженная версия себя (обводка + лупа слева, инпут скрыт); клик разворачивает колонку и фокусит поле.

## Чат и ввод
- **Автоскрытие скроллбара чата** (десктоп): тумб скрыт в покое, появляется при скролле, прячется через 0.8с простоя (`.chat-feed.scrolling`, JS-таймер).
- **Кнопка отправки** — квадратная (`aspect-ratio:1`). На мобилке иконка крупнее (26px) + состояние «можно отправить»: пустое поле — серая, есть текст/эмодзи — светлеет (`.send-btn.ready`).
- Иконка отправки обновлена на новый пиксельный самолётик (`currentColor` → тянет цвет тем).

## Терминал / виджеты
- Точки онлайн-юзеров (`.user-grid`) — всегда **одна строка**, заполняется по горизонтали (`nowrap`+`overflow:hidden`), без переноса на вторую строку на узких десктопах.
- Заголовок `TERMINAL` жёстко привязан влево (`#right-panel .section-head { justify-content: flex-start }`).

## Поиск / иконки / тексты
- Новая иконка-лупа (`search_icon.svg`, path + `currentColor`) во всех местах поиска; обновлено правило snow-темы (красила `rect` → теперь `color` на `.search-glyph`).
