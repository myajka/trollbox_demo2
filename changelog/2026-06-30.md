# Changelog — 2026-06-30 (понедельник)

Все изменения в `v1/index.html`.

## Slow mode (кулдаун отправки сообщений)
- Добавлен slow mode: после отправки поле ввода блокируется на время кулдауна (`SEND_COOLDOWN_MS`, сейчас 30с). В плейсхолдере тикает обратный отсчёт `Slow mode M:SS`, каретка скрыта, повторная отправка заблокирована (`isOnCooldown`). По истечении — поле снова активно.
- Состояние вешается классом `.cooling` на `.chat-input-row` (показ индикатора, скрытие каретки, отступ под иконку).

## Анимация — пиксельные песочные часы
- Во время кулдауна в строке ввода — пиксельные песочные часы (инлайновый SVG, цвет = акцент темы `--ac`). Песок ссыпается сверху вниз, затем часы **переворачиваются на 180°**; два переворота складываются в 360° — петля без скачка. Чистый CSS (`cd-flip`/`cd-drain`/`cd-fill`), учтён `prefers-reduced-motion`.
- Иконка вертикально по центру поля; текст «Slow mode …» отодвинут от часов через `text-indent`, наложения нет.

## Демо-переключатель шрифтов (для выбора командой)
- Шрифт текста сообщений вынесен в CSS-переменную `--font-body` (дефолт — прежний Roboto, вид без изменений). Бренд/ники/заголовки остаются на пиксельном `CHNOPixelCodePro`.
- В правом верхнем углу — панель выбора шрифта тела (демо-инструмент, помечен «remove before prod»). Варианты: Roboto, Inter, IBM Plex Sans, Geist, Onest, Noto Sans, Golos Text, Space Grotesk. У Geist нет кириллицы — для неё фолбэк на Onest (`'Geist', 'Onest', sans-serif`).
- Панель сворачивается в крошечный чип (клавиша H прячет её полностью), чтобы не мешать скринам. Меняется только текст сообщений — команда может вживую потыкать варианты и выбрать.
