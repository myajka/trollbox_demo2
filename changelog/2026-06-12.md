# Changelog — 2026-06-12 (четверг)

Все изменения в `v1/index.html`.

## Дизайн-ревью тем (база — default)
- **aurora**: квадратным элементам добавлены скругления (кнопки, инпуты, mood-btn, свотчи, плашки, скелетон); пиксельные аватары не трогаются.
- **snow**: убран light-on-light — `pe-name-input` (имя/био в Edit Profile) и `mybox-btn` перекрашены в тёмный текст; кольцо активного свотча — тёмная рамка + белый inset.
- **amber/hacker**: кольцо активного свотча (`box-swatch.active`/`pe-swatch.active`) — акцент темы вместо `#fff`.

## Загрузка после входа
- Добавлен loading-скелетон (`#skeletonScreen`, shimmer) после авторизации до готовности контента. Десктоп — 3 колонки, мобилка — 1 (`@media`). Показ — `showSkeleton()` в `setAuthState` (welcome→in); скрытие сейчас по таймеру 900мс (демо), бэк дёргает `hideSkeleton()` по факту загрузки.
- Убрана анимация появления боксов (CRT boot-in scan, `crtBootBoxes`) — её роль теперь у скелетона. Осталась только typewriter-анимация превью сообщений (`animateRoomPreviews`).

## Модератор / провайдеры входа
- **Режим модератора — только через Discord.** `𝕏` и `Telegram` входят как обычный юзер (`loginAsUser` сбрасывает модер-флаг `tb_mod`) — без кнопки создания бокса и без EDIT BOX. Discord включает модера (`enterModerator`). Применено и на welcome-экране, и в reg-wall.
- **Кнопка создания бокса** (`+` в строке поиска списка боксов) снова видна в режиме модератора (`applyModeratorUI` по `isMod()`).

## Сообщения
- **Delete message** — новый пункт в поп-апе по клику на сообщение: удаляет сообщение из текущего бокса (`deleteMessage`), красный акцент. В агрегированной ленте My Box пропускается.

## FIFA box — переработка виджетов
- **MY TEAM (новый, верх панели)**: поиск своей команды (скрытый оверлей-список по фокусу, поиск без диакритики — "tur" находит TÜRKİYE), follow в `localStorage`. Выбранная команда — чипом у заголовка с ✕. Карточка по статусу матча: LIVE-счёт с минутой / "NEXT MATCH IN 6d 03h" + соперник и дата в одну строку / FT-результат (W/L/D).
- **MATCHES (вместо COUNTDOWN + UPCOMING MATCHES)**: единая лента, live сверху (крупный счёт, пульс-минута, приглушённо-золотая обводка), upcoming — отсчёт прямо в строке. Команда фаната пинуется наверх (★). Пагинация по 6 (‹ prev · 1/4 · 20 matches · next ›). Расписание расширено до 20 матчей.
- **TOP MATCH — WHO WINS? (бывш. WHO WILL WIN?)**: голосовалка всегда по топ-матчу ленты (сейчас POR–URU), привязка к кликам по карточкам убрана. Состояние голосов — per-match (ключ матча). Цвета баров и графика opinion — по основному цвету флага/клуба каждой команды.
- **Клубы**: реестр `FIFA_CLUBS` (CHE, MCI, RMA, PSG, FCB, PAL) — в пикере MY TEAM и в матчах (Club WC). Логотипы с football-logos.cc, при ошибке загрузки — фоллбэк-бейдж с инициалами на цвете клуба.

## Integration / backend notes
Фронт-демо: фикстуры `FIFA_FIXTURES` (status: live/upcoming/finished, счёт, минута) и поллы захардкожены — бэку нужно отдавать расписание/live-счёт и принимать голоса. Follow хранится в `localStorage` (`fifaFollow`). Логотипы клубов — внешний CDN `assets.football-logos.cc` (есть локальный фоллбэк-бейдж).
