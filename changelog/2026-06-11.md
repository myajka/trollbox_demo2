# Changelog — 2026-06-11

Все изменения в `v1/index.html`. Обновлён ассет `v1/trolls/anon.svg` (новая иконка анонима).

## Вход / welcome / reg-wall
- **WEB3-вход помечен «soon»** — кнопка на welcome-экране неактивна (вход пока недоступен): без hover, не кликается; внешне как остальные кнопки (не приглушённая), с бейджем «soon» по центру.
- **Reg-wall переделан** — вместо `SIGN UP / LOG IN` теперь кнопки провайдеров с welcome-экрана (𝕏 / Discord / Telegram / WEB3 «soon»), без «Join anonymously». Клик по провайдеру логинит и закрывает модалку.

## Иконка анонима
- Новый `anon.svg` применяется **везде** для анонимного пользователя: собственный аватар в сайдбаре, профиле (десктоп и мобилка), сообщениях, reg-wall и превью в редакторе. Для авторизованного возвращается обычный тролль. Реализовано централизованно (`applyMyProfile` подставляет аватар по anon/auth-состоянию, вызывается из `setAuthState`).

## Модератор
- **EDIT BOX доступен модератору на любом боксе** (раньше — только на своём созданном). Кнопка видна модератору в шапке любого бокса, кроме My Box; `openEditBox` открывает редактирование системного бокса. Создание боксов остаётся скрытой moderator-only фичей.

## Прочее
- **Надпись «beta»** у логотипа TROLL.BOX в шапке (десктоп + мобилка) — маленькая, акцентного цвета, с отступом справа от вордмарка.
- **Онбординг-тур временно скрыт** (`ONBOARDING_ENABLED = false`) — глушит авто-старт и «Show tour again»; вернуть на `true`, когда будут финальные иллюстрации/тексты.

## Integration / backend notes
Чистый фронт. WEB3-вход и онбординг — выключены флагами/состоянием, бэк не трогают. Reg-wall/welcome-провайдеры — UI-каркас, привязать к реальной авторизации (𝕏/Discord/Telegram OAuth). EDIT BOX для модератора — на проде гейтить по реальной роли модератора.
